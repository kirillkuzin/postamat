# Support

## Questions and usage help

Use GitHub issues for reproducible bugs and clearly scoped enhancement requests. If Discussions are enabled for the repository, use Discussions for open-ended questions and design conversation.

## Bug reports

Please include:

- commit or version;
- OS and architecture;
- Go and Node.js versions when relevant;
- exact command or API request;
- expected behavior;
- actual behavior;
- sanitized logs or test output.

Do not include secrets, raw tokens, transfer tickets, encryption keys, URL fragments, SDP/ICE payloads, or plaintext file contents.

## Security reports

Do not use public support channels for vulnerabilities. Follow [SECURITY.md](SECURITY.md).
